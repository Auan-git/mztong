# 学习资料目录

本目录用于存放民职通 App「学习资料」页展示的资料，按学院分目录：

```text
学习资料/
├── 老年福祉学院/
├── 社会工作学院/
├── 康复工程学院/
├── 生命文化学院/
├── 婚礼文化与传媒艺术学院/
└── 儿童教育与发展学院/
```

## 怎么放资料

1. 进入对应学院目录，新建子文件夹（比如「2025-2026-1」「期末考试资料」）。
2. 把文件放进去，App 会自动读取并展示目录树。
3. 支持的格式：`.pdf` `.doc` `.docx` `.ppt` `.pptx` `.xls` `.xlsx` `.txt` `.md`。
4. 其它格式（压缩包、图片等）不会在列表里显示，但仍可通过 Gitee 网页直接查看。

## 命名建议

- 文件名尽量写清楚课程名与用途，例如 `老年社会工作-期末复习提纲.pdf`。
- 不要放带个人隐私、账号密码、未授权版权的资料。
- 大文件（>100MB）Git/Gitee 可能拒绝，建议先压缩或拆分。

## 同步说明

App 直接读取本仓库 `master` 分支上的内容：在 Gitee 网页上传或推送文件后，App 里下拉刷新（或重新进入学习资料）即可看到最新内容。
