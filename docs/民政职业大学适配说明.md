# 民职通 · 民政职业大学适配说明

本文档说明 `MZtong-Android` 这个分支做了什么改造、哪些配置是占位值、上线前必须核对什么。

## 1. 工程定位

- **来源**：本工程由开源项目 [AHUTong](https://github.com/OpenAHU)（安大通，Android 端）二次开发而来，遵循 GPLv3。
- **目标**：把原「安大通」改造为面向**民政职业大学**（简称「民职大」）的校园服务 App「**民职通**」。
- **保留的内部标识符**（有意不改，避免破坏 JNI 绑定、缓存与升级路径）：
  - 包名 `com.ahu.ahutong`、`applicationId`、类名 `AHUApplication` / `AHURepository` / `AHUCache` / `AHUTheme` / `AhuTong` / `AdwmhApi` 等；
  - 预编译原生库文件名 `libahutong_rs.so`；
  - MMKV / SharedPreferences 的部分 key 前缀。
  它们只出现在代码内部，不影响用户可见品牌。
- **已改造**：应用名、文案、图标、启动图、主题色、学校业务数据（校区/楼宇/浴室/电话本/天气/Mock）、接口域名（集中到 `SchoolConfig`）、文档与开源声明。

### 4.1 课表抓取链路（超星教务）

实现代码：`app/src/main/java/com/ahu/ahutong/data/chaoxing/`

| 步骤 | 请求 | 说明 |
| --- | --- | --- |
| 1 | `GET /admin?sfjrxk=1` | 读取登录页 `var publicKey`（RSA 公钥，SPKI Base64） |
| 2 | `POST /admin/login` | 密码用 `RSA/ECB/PKCS1Padding` 加密后 Base64；表单 `username`、`password`、空 `vcode`/`jcaptchaCode`/`rememberMe` |
| 3 | `GET /admin/pkgl/xskb/queryKbForXsd` | 从隐藏字段读 `xhid`（学生内部标识）、`xnxq`（学期）、`xqdm`（默认校区） |
| 4 | `POST /admin/xsd/kcapcx/checkSfkc`、`POST /admin/xsd/pkgl/xskb/checkWfwSfpj` | 与网页一致的可查看/已评教校验，`ret != 0` 直接报错 |
| 5 | `GET /admin/api/getZclistByXnxq` | 作息（`jcsjszList`：小节/大节/起止时间）、校历（`zclist`）、当前周（`dqzc`） |
| 6 | `GET /admin/pkgl/xskb/sdpkkbList` | 排课明细，一行 = 一次小节排课 |
| 7 | 本地转换 | 去 HTML 标签 → 解析周次（`1-5,7-18` / `1-20(单)`）→ 按「课程+星期+周次+教师+教室+大节」合并 → `Course` |

要点：

- Cookie 复用工程持久化 CookieJar（`AHUCookieJar`），**冷启动可复用会话**；会话失效会重定向回登录页，此时用本地缓存的学号/密码自动重登一次。
- 登录密码只用于请求加密，不落盘明文以外的位置（沿用原工程 `AHUCache.saveWisdomPassword` 的本地存储策略）。
- 课表节次为 **12 小节**（08:10–20:30，含午间 12:00/12:55 两节），不是原工程的 13 节；节次时间表由 `TimetableProvider` 维护，拉取时用教务作息覆盖并持久化。
- **JSON 接口必须带 ajax 头**：`getZclistByXnxq`、`sdpkkbList`、`checkSfkc`、`checkWfwSfpj` 若不发 `X-Requested-With: XMLHttpRequest` 与 `Accept: application/json`，超星会返回 **HTTP 500**（已实测），课表抓取会直接失败。
- 会话失效识别：超星返回的登录超时 JSON 没有 `ret` 字段，只有 `msg: "登录超时,请重新登录！"`；客户端会把这种响应（以及被重定向回登录页）识别成会话失效，自动用本地缓存学号/密码重登一次。
- 已确认的边界：登录若弹出验证码会返回 `CAPTCHA_REQUIRED`（不识别、不绕过，提示用户网页端完成）；学期默认取网站当前学期。
- 已知未接入：成绩、考试、空教室、评教仍走旧强智接口（不可用）；纯网络课程（页面备注中的「网络教师」课程）不伪造周次与上课时间。

### 4.2 已修复问题（1.1.0）

**症状**：旧版本加载课表提示 `加载课表失败：Cannot parse current semester`。

**原因**（已用真实教务接口复现）：

1. 超星的 JSON 接口（作息 / 排课 / 两项校验）在**缺少 `X-Requested-With: XMLHttpRequest`** 时会返回 HTTP 500，客户端第一次实现漏发了该头，课表抓取必然失败；
2. 失败后代码回退到旧的强智爬虫（`jw.bcsa.edu.cn`），该调用抛出 `Cannot parse current semester`，把超星的真实错误覆盖成误导性提示。

**修复**：

- JSON 接口统一走带 ajax 头的 `getJson()`；
- 课表只走超星链路，删除旧爬虫回退，错误原样展示；
- 补全会话失效识别（登录超时 JSON / 登录页 HTML）并自动重登；
- 新增 2 项回归单测覆盖「登录超时 JSON」识别。

### 4.3 周次与日期计算规则（1.2.1 修复）

**数据来源**：教务作息接口的 `zclist`（第 1 周周一，如 `2026-08-31`）与 `dqzc`（抓取时的当前周次），写入 `AHUCache`。

**计算规则**：

- `周次 = (今天 - 第 1 周周一) / 7 + 1`，限制在 `1..20`，周一为一周起点；
- 开学日期缺失时，用「教务周次 + 抓取日期」反推第 1 周周一（`TeachingWeekPolicy.startDateFromTeachingWeek`），并写回缓存；
- 界面日期区间 = 第 1 周周一 + `(周次 - 1) * 7`，共 7 天；「今天」高亮按系统日期实时计算。

**已修复的三类错乱**：

| 场景 | 旧行为 | 修复 |
| --- | --- | --- |
| 首次登录 / 切换学期 | `loadConfig` 在拉课表前执行，开学日期还没写入，显示「第 1 周 + 本周日期」 | 拉取课表成功后立即 `reloadScheduleConfig()` 重算 |
| 开学日期缓存缺失（升级/清缓存） | 直接回落到 `默认第 1 周` | 用教务 `dqzc` + 抓取日期反推开学日期并写回 |
| App 跨天 / 跨周一直开着 | 「今天」高亮与周次不更新 | 界面按系统日期实时算今天；每 30 秒检测跨天，跨天自动重算 |
| 没拿到开学日期 | 误显示「第 1 周 · 本周」 | 明确提示「尚未获取开学时间，请下拉刷新」 |

### 4.4 成绩查询链路（超星教务，1.3.0 接入）

实现代码：`data/chaoxing/ChaoxingGradeModels.kt`、`ChaoxingParsing`（成绩部分）、`ChaoxingClient.fetchGrades`、`ChaoxingGradeRepository`。

| 步骤 | 请求 | 说明 |
| --- | --- | --- |
| 1 | `GET /admin/xsd/xsdcjcx/qbcjcx` | 成绩查询页；从 `input#queryxsdcjcxGridIdFields` 取 `queryFields`，从 `startXnxq`/`endXnxq` 下拉框取可选学期，从 `kcxz`/`kclx`/`kclb` 取课程性质等中文名 |
| 2 | `GET /admin/xsd/pj/xspj/getPjxtsz` | 评教设置（与官网一致先读一次，失败不阻断，最终以接口 ret 为准） |
| 3 | `POST /admin/xsd/xsdcjcx/xsdQueryXscjList?fxbz=0&gridtype=jqgrid` | 分页取成绩：`page.pn`、`page.size=100`、`sort=id`、`order=asc`、`startXnxq/endXnxq`（全量为 `001`）、`queryFields`；必须带 ajax 头 |
| 4 | 校验 | 每页校验 `page/rows/total/totalPages` 一致性、记录 id 去重、读取总数 = 服务器总数；任何非 `ret=0` 按拒绝查询处理 |
| 5 | 转换 | 按学期分组 → App `Grade`；成绩原文保留（「优秀/合格」不换算）；只有接口返回 `jd` 才显示单科绩点 |

要点与限制：

- `fxbz=0` 为本人主修成绩；未读取辅修/微专业。
- 学期默认选中「最近一个有成绩的学期」（避免默认落在空学年）。
- 全程/学期专业排名「暂无」：超星成绩接口不提供排名数据（原强智排名接口在民政环境不可用）。
- 平均绩点：仅当该学期所有课程都有 `jd` 时才计算加权平均，否则显示「暂无」；不拿 `xfjd` 或数字成绩自行折算。
- 成绩页也会在会话过期时被重定向到登录页，客户端识别为 `SESSION_EXPIRED` 后自动用本地学号/密码重登一次。

## 5. Rust / Native 说明（务必阅读）

- APK **默认不打包** `libahutong_rs.so`（`app/build.gradle.kts` 的 `packaging { jniLibs { excludes += "**/libahutong_rs.so" } }`）。
- `RustSDK` 启动时优先加载热更新目录（`filesDir/jniLibs`）里的 `.so`，否则尝试 `System.loadLibrary("ahutong_rs")`。
- 该预编译库**内部仍硬编码原学校域名**（jw / ycard / adwmh / openahu 等），且 JNI 符号按 `com.ahu.ahutong.sdk.RustSDK` 绑定，无法在 Java/Kotlin 侧改写。
- 因此本分支全新构建后的课表链路是：
  1. `SdkDataSource` **优先走超星教务**（`ChaoxingScheduleRepository`，纯 Kotlin/OkHttp/Jsoup，不依赖原生库）；
  2. 超星失败后才尝试旧的 Rust 本地服务 → JNI → Android 爬虫（历史兼容，民政环境不可用）；
  3. 成绩/考试/一卡通等旧功能仍依赖原项目接口，暂不可用。
- 若要复用 Rust 服务（登录、课表解析、一卡通），需要基于上游 `GuiXu-Rust` 重新编译并把域名改为民政职业大学，然后放入 `jniLibs`；届时再把 `USE_PRECOMPILED_RUST_SERVICE` 接到数据源选择处。

## 8. 已知限制

- 教务系统（超星）已接入：登录与课表可用；成绩、考试、空教室、评教、一卡通、缴费、失物招领仍指向旧占位接口，暂不可用。
- Rust 预编译库沿用原项目，内部协议与地址未适配。
- 更新服务、灰度、遥测、验证码 OCR 均指向占位域，相关请求会失败并被静默处理。
- 仅打包 `arm64-v8a`，模拟器与其他 ABI 无法安装。
- 未生成新的商店截图；`pic/` 目录已从本分支移除。
- **超星课表尚未在线联调**：协议按 `chaoxing-schedule` 脚本实测移植，解析层有离线单测；真实账号登录、验证码分支、学期切换需要现场验证。
- 超星教务为网页内部接口，系统改版可能导致字段变化：解析层遇到未知节次/周次/结构会直接报错，不会把失败当成空课表。
